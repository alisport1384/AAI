# هوشیار (AAI) — v0.16.0

[![Android CI](https://github.com/alisport1384/AAI/actions/workflows/android.yml/badge.svg)](https://github.com/alisport1384/AAI/actions/workflows/android.yml)

> **جدید در 0.16 — IronPin + Qwen RAG + سه تب:** دیتابیس آفلاین ۱۸ خانواده آهن‌آلات (از صفر تا صد بچه‌فهم)، تحقیق موضوعی با همهٔ موتورها (شامل گردو و ذره‌بین) و ذخیرهٔ Qwen-فهم (چانک ۴۵۰ توکن + متادیتا)، تب‌های پرسش/دانش/تنظیمات. راهنما: [`docs/V16-IRON.md`](docs/V16-IRON.md).

دستیار **روی-دستگاه** برای بازاری که **کاربر خودش معرفی می‌کند**: خودش در وب
می‌گردد، اطلاعات را می‌فهمد، **دسته‌بندی و ذخیره** می‌کند، کهنه‌ها را **بازبینی و اصلاح**
می‌کند، دادهٔ خودش را ویرایش می‌کند، لاگ را به Markdown می‌نویسد و از همه‌چیز بک‌آپ می‌گیرد.

- هیچ بازاری در برنامه کامپایل نشده است؛ بازار داده است (`MarketPack` ↔ JSON).
- API/توکن ابریِ پیش‌فرض، SDK سرویس پولی یا تلمتری وجود ندارد. بک‌اند شخصیِ اختیاریِ
  نسخهٔ ۰٫۱۵ کلید اتصال خودش را فقط به انتخاب کاربر می‌گیرد.
- در حالت پیش‌فرض **ارتباط بیرونی برای جستجوی وب** (GET به موتورهای عمومی) است؛
  اتصال اختیاری به سرور شخصی فقط برای دستور صریح اسناد/آپلود فعال می‌شود.
  ذخیرهٔ گفتگو و پاسخ‌سازی معمولی روی دستگاه‌اند.
- پرسش‌ها فقط با **شاهد** پاسخ داده می‌شوند؛ در نبود شاهد، صریح «نمی‌دانم».
- از v0.7 یک **مدل زبانی محلی** (اختیاری، یک‌بار دانلود) جمله را بازنویسی می‌کند؛ از v0.8
  همان مدل **تصمیم هم می‌گیرد** (شکستن موضوع به وجه، برچسب لایه) ولی اعداد و استنادها همان
  شاهدها هستند و مدل اجازهٔ ساختن عدد تازه ندارد.
- بخش آگهی هست، اما منبع اصلی نیست: هوش خودش داده را از وب پیدا و ذخیره می‌کند.

### تازه در v0.15.0 — ارتقای عملی و اختیاری طبق معماری L0–L9

* **اپِ مستقل حفظ شد:** بدون سرور/حساب/کلید پولی همان گفتگو، جستجوی وب و مدل محلیِ اختیاری کار
  می‌کنند. `حساب کن: 2^10 * sqrt(144)` یک حسابگر محدود و بدون اجرای کد دلخواه است.
* **بک‌اند شخصیِ اختیاری** (`selfhost/`) با Python و SQLite FTS5 روی سخت‌افزار خود کاربر:
  فایل‌های متن/Markdown/CSV/HTML را به انتخاب او برای *همان گفتگو* نمایه می‌کند.
  `از اسنادم: ...` فقط نقل‌قول‌های سند با شناسهٔ منبع می‌دهد، نه قیمتِ زنده یا ادعای مدل.
  پرسش‌های عادی و تاریخچهٔ کامل خودکار به این سرور فرستاده نمی‌شوند.
* اتصال HTTPS با pin گواهی و کلید دسترسی، محدودیت حجم/نرخ، متریک بدون متن پرسش، حذف اسناد
  یک گفتگو و پشتیبان مستقلِ پایگاه دادهٔ سرور افزوده شد. کلید روی گوشی با Android Keystore
  رمز می‌شود و در ZIP بک‌آپ اپ نیست. بدون سرور، پرسش مستند امتناع می‌کند ولی اپ همچنان کار می‌کند.
* این **نسخهٔ مرحله‌ای** vLLM/70B، Qdrant/بردار، PDF/OCR، اجرای Python دلخواه، بحث چندعامله،
  LoRA خودکار یا معیارهای دقتِ ادعاشدهٔ سند را پیاده نمی‌کند. نرم‌افزار/API هزینهٔ اشتراک
  ندارد؛ رایانه، برق و اینترنتِ شخصی هزینهٔ واقعی دارند. دستور نصب و جدول انطباق/محدودیت‌ها:
  [`docs/V15-HYBRID.md`](docs/V15-HYBRID.md).
* **ساخت محلی ۰٫۱۵ موفق:** ۱۲ آزمون Python و ۴۹۹ آزمون Android/JVM، بدون شکست/رد؛
  APK دیباگ `hushyar-0.15.0-debug.apk` (SHA-256:
  `0c7ccf52aa147e7e0c90d490ce5b4e4c47cceae98b73ab769abf0de2cba48cc1`).
  گواهی آن با APK محلی ۰٫۱۴ یکسان، اما با APK قدیمی ۰٫۱۳ متفاوت است؛ آزمون دستی گوشی
  انجام نشده. بک‌آپ گوشی ممکن است پرسش‌ها و **نقل‌قول‌های سند** را هم داشته باشد.

  APK، ارتقای درجا ممکن نیست. تا بیرون‌کشیدن بک‌آپ نسخهٔ قدیم، آن را حذف نکن.
* ساخت **محلی** نسخهٔ ۰٫۱۴ و مجموعهٔ آزمون‌ها موفق بود: **۴۹۱ آزمون، صفر شکست/ردشده**؛ APK

  میلی‌متر تا متر، مترمربع، لیتر، تومان/ریال. «قیمت دوجین» از «قیمت عدد» ساخته می‌شود و برعکس.
* **بستهٔ دانش، داده است نه کد** (`domain/DomainPacks.kt`): بستهٔ فلزات و بستهٔ **پوشاک**
  (تی‌شرت، شلوار، پیراهن، سویشرت، پارچه) و بی‌نهایت بستهٔ دیگر. کاربر با یک جمله
  «من فروشگاه تی‌شرت و شلوار هستم، سایز و رنگ مهم است» بستهٔ خودش را می‌سازد.
* **دانش نوع‌دار**: «کالا + ویژگی + مقدار + یکا + منبع + تاریخ» در همان انبار دانش؛ قیمت کهنه
  خودکار کنار می‌رود و قیمت تازه جای آن را می‌گیرد.
* **مدل، یادگیرنده شد نه بازنویس**: علاوه بر انتخاب کار، از متنِ نتیجه ویژگی استخراج می‌کند —
  ولی هر عددی که در متن منبع نباشد دور انداخته می‌شود (تست دارد).
* **مدل بزرگ‌تر**: Gemma 3 1B و Qwen3 1.7B و Llama 3.2 3B به فهرست دانلود اضافه شدند، با اندازه
  و SHA-256 خوانده‌شده از API خود HuggingFace.

## ساخت

```bash
# پیش‌نیاز: JDK 17، Android SDK (platform 35، build-tools 35)
gradle testDebugUnitTest assembleDebug
```

برای ساخت محلیِ دو فایل مستقل، هر APK را پیش از ساخت بعدی کپی کنید؛ Gradle نام `app-debug.apk` را بازاستفاده می‌کند:

```bash
gradle -PciAbi=armeabi-v7a :app:assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk Hushyar-0.15.1-armeabi-v7a-debug.apk
gradle -PciAbi=arm64-v8a :app:assembleDebug
cp app/build/outputs/apk/debug/app-debug.apk Hushyar-0.15.1-arm64-v8a-debug.apk
```

بدون `ciAbi`، ساخت دیباگ محلی همچنان چندمعماری است. اکشن هر دو APK مخصوص **ARMv7 و ARM64** را جدا می‌سازد، معماری و وجود موتور محلی/امضا را در هر کدام بررسی می‌کند و همراه `SHA256SUMS.txt` در artifact `hushyar-debug-apk` می‌گذارد. هش و امضای بسته‌های اکشن را از همان اجرا بخوانید؛ امضای Debug نسخهٔ رسمی انتشار نیست.

## اصولی که در کد قابل بازرسی‌اند

1. **بدون حدس:** هر عدد در پاسخ به یک آگهی/سند ارجاع دارد (`Critic`)، و ویژگی نامعلوم «نامعلوم» می‌ماند.
2. **بازار = داده:** تعویض بازار فقط JSON است.
3. **قطعیت:** همهٔ منطق تحلیل و پاسخ، تابع خالص ورودی است؛ همان ورودی، همان خروجی.
4. **حریم خصوصی:** داده در SQLite محلی، بدون پشتیبان‌گیری ابری (`allowBackup=false`)، بدون تلمتری.
5. **وب فقط داده است:** هر صفحه پیش از استفاده برای شواهد، از نظر «تزریق دستور» بازرسی
   می‌شود (`InjectionGuard`)؛ صفحهٔ آلوده هرگز شاهد نمی‌شود.
6. **هر عمل قابل بازبینی است:** تغییر داده، جستجو و پاسخ در جدول `event` و `audit`
   ثبت می‌شود و به `brain.md` درمی‌آید.
