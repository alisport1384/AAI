# بک‌اند اسناد شخصی هوشیار — اختیاری، بدون API پولی

راهنمای راه‌اندازی TLS، اثر انگشت گواهی، تنظیم اپ، پشتیبان و محدودهٔ قابلیت‌ها:
[`../docs/V15-HYBRID.md`](../docs/V15-HYBRID.md).

از ریشهٔ مخزن، یا از پوشه‌ای که ZIP بک‌اند شخصی در آن استخراج شده است:

```bash
python3 -m unittest selfhost.test_hushyar_backend -v
python3 -m selfhost.hushyar_backend --help
```

وابستگیِ pip ندارد؛ به Python 3.10+ و SQLite با FTS5 نیاز دارد. ۱۲ آزمون یکپارچهٔ
محلی می‌گذرند. بدون گواهی TLS فقط روی localhost گوش می‌دهد. برای دسترسی از گوشی،
کلید ۳۲نویسه‌ای و گواهی HTTPS با SAN هم‌نامِ IP میزبان لازم‌اند. پایگاه داده و بک‌آپ
اسناد متنِ آشکار دارند؛ آنها را محرمانه نگه دارید. هیچ متن/کلید/فایل خصوصی یا پایگاه داده‌ای
را داخل مخزن Git قرار ندهید. پرسش عادی اپ هیچ تماسی با این سرویس نمی‌گیرد.
