# دامنهٔ نسخهٔ ۳ — هوشی که خودش می‌رود، می‌فهمد، دسته‌بندی می‌کند و ذخیره می‌کند

نسخهٔ **۰.۳.۰** همان اپ v0.2 است با یک تغییر بنیادی: **بخش آگهی دیگر منبع اصلی نیست.**
آگهی‌ها می‌مانند (برای تحلیل قیمت و ورود دستی/CSV)، اما وقتی پرسشی پاسخ محلی ندارد،
خودِ هوش تصمیم می‌گیرد چقدر و چطور جستجو کند، شاهد جمع می‌کند، آن را دسته‌بندی و ذخیره
می‌کند، و دفعهٔ بعد از همان دانش پاسخ می‌دهد — و اگر کهنه شود، خودش بازبینی و اصلاح می‌کند.

## ۱) حلقهٔ پژوهش خودکار (خواستهٔ اصلی این نسخه)

`domain/Research.kt` — `DeepResearcher`

```text
while (دور < بودجه) و (پوشش < هدف):
    پرسش = پرسش پایه (دور اول) یا پرسشِ مبتنی بر شکاف (دورهای بعد)
    نتایج = جستجوی چند-موتوره
    صفحه‌ها = واکشی صفحات تازه (URL تکراری هرگز دو بار)
    شاهد = استخراج جملات مرتبط از همهٔ صفحه‌ها
    پوشش = مدل پوشش (مرتبط‌بودن، عدد، تنوع منبع، ویژگی‌های بازار)
    اگر پوشش ≥ هدف → توقف «کافی»
    اگر صفحهٔ تازه‌ای نبود → توقف «چیز تازه‌ای نیست»
```

**شکاف‌ها (Gaps)** همان چیزی است که «تا زمانی که لازم است» را معنا می‌دهد:
مرتبط‌بودن کم، نبودِ عدد/قیمت وقتی پرسش عدد می‌خواهد، تک‌منبعی بودن، ویژگی‌ای از بازار
که پرسش به آن اشاره کرده ولی شاهدی ندارد، و کهنه بودن دانش موجود. هر دور، پرسش را
مبتنی بر **ضعیف‌ترین شکاف** بازنویسی می‌کند (نه تکرار همان جستجو).

**بودجه** (چون جستجوی بی‌نهایت یعنی باتری و دادهٔ بی‌نهایت): `سریع` ۲ دور/۴ صفحه،
`متعادل` ۳ دور/۸ صفحه، `عمیق` ۵ دور/۱۴ صفحه + سقف زمانی. از تب «دانش» قابل انتخاب است.

اگر دانش موجود از قبل کافی باشد، حلقه **حتی یک درخواست هم نمی‌فرستد**.

## ۲) انبار دانش (یادگیریِ ماندگار از وب)

`domain/Knowledge.kt` — `KnowledgeItem` + `KnowledgeBank`

| مفهوم | معنا |
|---|---|
| `topic` | کلید موضوع از پرسش (بدون کلمات پرسشی) → پرسش تکراری به همان دانش می‌خورد |
| `claim` | جملهٔ **عیناً** برگرفته از صفحه (استخراجی، نه بازنویسی) |
| `url` / `domain` | منبع؛ تنوع دامنه در پوشش و اعتماد اثر دارد |
| `numericValue` + `unit` | عدد و واحد (تومان/ریال/درصد/…) برای تشخیص تغییر |
| `lastVerifiedAt` + `ttlDays` | تازگی؛ `TTL` پیش‌فرض ۴۵ روز |
| `sourceCount` | تعداد منابع هم‌رأی |
| `supersededById` | اگر دادهٔ تازه‌تر جایگزینش کرد، حذف نمی‌شود؛ فقط علامت می‌خورد |

**پنج تصمیم ادغام** (`KnowledgeDecision`):

| تصمیم | کِی | اثر |
|---|---|---|
| `NEW` | موضوع تازه یا ادعای سازگار و متفاوت | ردیف تازه |
| `REFRESH` | همان ادعا یا عددِ در محدودهٔ ۱۰٪ | تاریخ بازبینی و تعداد منابع به‌روز می‌شود |
| `CORRECT` | همان موضوع، عددِ متفاوت > ۱۰٪ | مقدار تازه فعال، مقدار قبلی **نگه داشته و علامت‌خورده** |
| `CONFLICT` | یکی می‌گوید هست، دیگری می‌گوید نیست (قطبیت نفی) | هر دو ذخیره؛ کهنه‌تر علامت می‌خورد، اعتماد کاهش می‌یابد |
| `IGNORE` | تکرار با اعتماد کمتر | بدون تغییر |

**اصلاح با دلیل**: کاربر در «آنچه آموختم» می‌بیند «مقدار قبلی با دادهٔ X اصلاح شد»؛
تاریخ هم پاک نمی‌شود تا قابل بازرسی باشد.

## ۳) بخش آگهی: می‌ماند، ولی داده‌اش هم می‌تواند از وب بیاید

`ListingHarvester` جملاتی را که **قیمت با واحد روشن** دارند به رکورد آگهی تبدیل می‌کند:
`source = "وب:<دامنه>"`، `url` صفحه، `priceIrt` از `PriceParser`، شناسهٔ محتوا-محور
(`fnv1a64(url|price)`) تا دوباره‌کاری نشود. جمله‌های بدون قیمت روشن رد می‌شوند
(شمارش «ردشده» در گام `listing.harvest` گزارش می‌شود). آگهی‌های دستی و CSV مثل قبل کار می‌کنند.

## ۴) قاعده‌های امنیتی که تغییر نکردند

1. **وب داده است، نه دستور.** صفحهٔ آلوده (`InjectionGuard`) هرگز شاهد نمی‌شود و
   در گام «صفحهٔ کنارگذاشته‌شده» با دلیل گزارش می‌شود.
2. **هر عدد منبع دارد.** پاسخ استخراجی است؛ بولت‌های `W1…` عیناً از صفحه‌اند.
3. **امتناع صریح.** اگر پس از دورها شاهدی نبود: «پس از N دور شاهد قابل استفاده‌ای نبود»
   + خطای موتورها. هیچ پاسخی ساخته نمی‌شود.
4. **بدون API/کلید.** فقط GET به موتورهای عمومی؛ `403/429` → خاموشی موتور، بدون دور زدن.

## ۵) دستورهای تازه

| دستور | کار |
|---|---|
| `تحقیق کن: ...` | جستجوی عمیق صریح، حتی اگر آگهی محلی پاسخ داشته باشد |
| `بروزرسانی کن` | دانش کهنه را دوباره پژوهش می‌کند؛ اصلاح‌ها را گزارش می‌دهد |
| `چه چیزهایی یاد گرفتی؟` | گزارش انبار دانش با منبع و تاریخ بازبینی |

## ۶) انحراف‌های صادقانه

| مورد | وضعیت | دلیل |
|---|---|---|
| خزش بی‌پایان وب | نیست (بودجه‌دار) | بدون سقف، روی موبایل یعنی باتری/دادهٔ بی‌کنترل و ریسک مسدودشدن؛ سقف صریح و قابل تنظیم است |
| مدل زبانی برای بازنویسی ادعا | نیست | پاسخ استخراجی است تا هر جمله قابل ردیابی بماند (هزینهٔ توهم صفر) |
| یادگیری از کلیک/رفتار کاربر | نیست | پیش‌فرض حریم خصوصی؛ فقط ترجیح‌های صریح (`ذخیره کن`) |
| مرور زمان‌بندی‌شده در پس‌زمینه | نیست | بدون WorkManager اجرای دوره‌ای انجام نمی‌شود؛ بروزرسانی با دستور یا هنگام پرسش کهنه انجام می‌گیرد |
| حذف کامل صفحه‌های تکراری بین دامنه‌ها | تقریبی | simhash ≤ ۱۰ برای متن و canonical URL برای لینک؛ بازنویسی‌های سنگین را نمی‌گیرد |
