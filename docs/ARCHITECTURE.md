# معماری هوشیار (v0.11)

یک نگاه از بالا، تا کسی که تازه وارد می‌شود بداند هر فایل چه کاری می‌کند و کدام «قاعدهٔ سخت» را
نباید بشکند.

```
پرسش کاربر
   │
   ├─ AppViewModel.ask
   │    ├─ «من فروشگاه … هستم»  → DomainSetup → بستهٔ دانش سفارشی در preference
   │    ├─ LocalPlanner.decide   → مدل محلی (اگر نصب و روشن) یا قاعدهٔ ثابت
   │    │        کارها: دانش / جستجو / یادگیری / گفتگو / روشن‌سازی
   │    └─ Agent.run
   │         ├─ 1  دستور داده (ذخیره/فراموش/بک‌آپ/تحقیق …)
   │         ├─ 2  کاتالوگ آگهی‌های خودت (آفلاین، دقیق)
   │         ├─ 2.5 MaterialBrain   — فلزات: جدول استاندارد + فرمول + قیمت
   │         ├─ 2.6 AnyDomainBrain  — هر کالای دیگر: بستهٔ دانش + دانش نوع‌دار + یکاها
   │         ├─ 3  حافظهٔ کاربر
   │         ├─ 3.5 پروندهٔ پاسخ قبلی (فقط با تطابق دقیق موضوع و کالا)
   │         ├─ 4  دانش ذخیره‌شده
   │         └─ 5  پژوهش خودکار (SearchCore → DeepResearcher → Critic)
   │
   └─ پاسخ: متن + بولت + منبع + فرمول + تاریخ + آنچه یاد گرفت
```

## قاعده‌های سختی که نباید شکسته شوند

1. **هیچ عددی از مدل زبانی نمی‌آید.** مدل می‌تواند انتخاب کند، پیشنهاد بدهد و از متن استخراج
   کند؛ عددِ نهایی یا از جدول/دانش است یا از محاسبه‌ای که فرمولش چاپ می‌شود، یا از متنی که عددش
   در همان متن دیده شده است.
2. **هر پاسخ باید بتواند منبعش را نشان دهد**؛ اگر نتواند، «نمی‌دانم» می‌گوید.
3. **حدس، دانش نیست.** سایز نامعلوم، بستهٔ بی‌اندازه، قیمتِ کهنه — همه صریح اعلام می‌شوند.
4. **حافظه و دانش** در SQLite می‌مانند و در پشتیبان می‌آیند؛ مدل در APK نیست.
5. **شبکه فقط جایی که کاربر می‌بیند**: جستجوی موتورها، واکشی صفحه‌های همان نتایج. بدون حساب،
   بدون کلید، بدون واسطه.

## فایل‌ها

| فایل | نقش |
|---|---|
| `domain/Agent.kt` | حلقهٔ عامل و ترتیب مراحل بالا |
| `domain/Search.kt` | موتورها، تجزیهٔ SERP، امتیازدهی، استراحت پله‌ای موتورها |
| `domain/Research.kt`, `DeepStudy.kt` | پژوهش دولایه و مطالعهٔ موضوع |
| `domain/Knowledge.kt` | ادغام دانش، تعارض، کهنگی |
| `domain/Materials.kt`, `SteelMath.kt`, `MaterialBrain.kt` | بستهٔ فلزات (v0.10) |
| `domain/AnyDomain.kt` | یکاها، چارچوب پرسش، دانش نوع‌دار (v0.11) |
| `domain/DomainPacks.kt` | بسته‌های دانش به‌شکل داده + ساخت بسته از حرف کاربر |
| `domain/AnyDomainBrain.kt` | مغز بی‌حوزه + تبدیل نرخ + استخراج (کد و مدل) |
| `domain/LocalAI.kt`, `LocalAgent.kt` | مدل محلی: فهرست، چارچوب گفتگو، تصمیم، استخراج |
| `data/*` | SQLite، فایل‌ها، HTTP، دانلود مدل |
| `ui/*` | صفحه‌ها؛ هر کارت یک بخش از این معماری است |
